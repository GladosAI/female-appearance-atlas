# 女性之美

**女性キャラクター外見図鑑**

[中文](README.md) · [English](README.en.md) · **日本語**

ゲーム・アニメ・キャラクターデザインに使える、検索可能なビジュアル資料集です。コンテンツ版74.0には **7,241件の図解付き項目、722枚の一覧画像、211カテゴリ** を収録しています。髪型、顔・表情、体型・ポーズ、服装、装飾品、幻想的な身体形態、素材、画風、カメラ表現、人物のいるシーンを調べられます。

[日本語で閲覧](https://gladosai.github.io/female-appearance-atlas/?lang=ja) · [ソースコード](https://github.com/GladosAI/female-appearance-atlas) · [ダウンロード](https://github.com/GladosAI/female-appearance-atlas/releases/latest) · [不具合報告](https://github.com/GladosAI/female-appearance-atlas/issues)

言語メニューから中国語・英語・日本語を選べます。検索は3言語の項目名に対応しています。外見カードに資料を集め、複数のカードを管理できます。選んだ項目名だけを整理したAI用プロンプトを編集・コピーでき、プロンプトの言語は画面の言語と別に選択できます。カード、メモ、プロンプト履歴はブラウザ内だけに保存されます。画像生成APIやクラウドアカウントは必要ありません。

このプロジェクトは、自由に資料を選ぶためのライブラリです。必須パーツを定めたキャラクター作成手順や、自動画像生成機能はありません。

英語の項目名には、従来のカタログにある英語名を使用しています。英語・日本語の説明と日本語名には、確認状態を記録した機械翻訳の草稿が含まれます。操作画面と用語は追加確認の対象ですが、専門家による翻訳を保証するものではありません。過去のMarkdown文書、画像生成時の原記録、画像内の文字は原文のままです。未翻訳部分は利用可能な原文で表示します。

オフラインでは、リリースに記載された **ソースZIP・画像リソース・オフライン画像読み取りデータ** をダウンロードし、同名の `female-appearance-atlas` フォルダにまとめて展開してから `index.html` を開きます。プログラム更新では指定の画像リソースを再利用するため、変更のない画像を再ダウンロードする必要はありません。

協力方法は [日本語の貢献ガイド](CONTRIBUTING.ja.md) と [翻訳の保守手順](docs/localization.md) を参照してください。Python 3.10以上で静的サイトを構築し、Node 22以上でブラウザ検証や画像処理を行います。構築・閲覧に有料サービスは不要です。
