# Beauty of Women

**Female Character Appearance Atlas**

[中文](README.md) · **English** · [日本語](README.ja.md)

A searchable visual reference library for game, anime and character design. Content edition 74.0 contains **7,241 illustrated entries, 722 reference sheets and 211 categories**. Browse hairstyles, faces and expressions, body shapes and poses, clothing, accessories, fantasy forms, materials, art styles, camera language and character scenes.

[Browse in English](https://gladosai.github.io/female-appearance-atlas/?lang=en) · [Source](https://github.com/GladosAI/female-appearance-atlas) · [Downloads](https://github.com/GladosAI/female-appearance-atlas/releases/latest) · [Report an issue](https://github.com/GladosAI/female-appearance-atlas/issues)

Select Chinese, English or Japanese in the language menu. Search accepts names in all three languages. Appearance cards let you collect references into multiple independent cards and export editable, name-only AI prompts. Prompt language can differ from interface language. Cards, notes and prompt history stay in your browser; there is no image-generation API or cloud account requirement.

This is a reference library, with freely selectable alternatives. It does not prescribe mandatory character parts or automatically combine references into an image.

English names reuse the original catalog's English fields. English and Japanese descriptions, and Japanese names, include machine-assisted drafts with recorded review status. Interface and terminology receive additional review; this is not a claim of professional translation. Historical Markdown documents, original generation records and text inside images remain in their original language. Missing translations fall back to an available original field.

For offline use, download the **source ZIP**, **image resources** and **offline image-reading data** linked in the release, then merge their `female-appearance-atlas` folders. Open `index.html`. Updates to the program reuse the declared image resource edition; a code update does not require downloading unchanged images again.

To contribute, see [English contribution guide](CONTRIBUTING.en.md) and [translation maintenance](docs/localization.md). Python 3.10+ builds the static site; Node 22+ is used for browser checks and image preparation. No paid service is required to build or browse the project.
