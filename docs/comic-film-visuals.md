# 漫画单格与影视关键帧

[漫画单格与格内表现](../index.html?section=branch_comic_panel_language) · [影视分镜与关键帧设计](../index.html?section=branch_film_visual_development)

共 72 项，其中漫画单格 56 项、影视设计 16 项，位于主目录“画风与视觉表现”。每项是一幅独立示意，不依赖额外的生成页面。

漫画部分关注一格里的格框与画幅、用墨与笔触、人物与场景主次、痕迹与回忆、动势、符号、气泡与拟声字；这些表达可与不同漫画画风组合。出框只突破示例内部的格框；画中画是同一示例中的细节插格。窄横格、竖长格等的内框保留在完整示例图中，不把网站卡片裁成对应形状。

眼镜反光、空白眼、灵魂出窍、石化、融化、大汗滴和青筋等属于夸张的漫画表演符号；结合上下文表达情绪，不代表实际生理状态。回忆叠画在同一格里叠入主观意象，与表示连续动作的残影区分。虚线、波浪、画外对白和图像心声展示气泡的语气与信息来源。图鉴按视觉作用命名，不把这些名称当作统一行业术语。

影视部分包括分镜缩略草图、清线与灰阶分镜、布局和表演稿、预演帧，以及凝聚空间、人物、动作、情绪、灯光和特效的概念关键帧。这里按创作用途归纳，不能视作所有剧组统一的命名标准。

色彩脚本通常是一组画面，本图鉴取其中单帧展示光色方案。“概念关键帧”也不同于动画插值关键点和视频编码I帧。覆绘示例以本项目AI原创画面模拟设计过程，没有使用真实剧组实拍底图。

所有配图均使用内置 imagegen 原创生成，非已有漫画页、影视截图或制作公司的设计原稿。示例文字用于展示气泡与版面，提示词导出仍只包含所勾选词条的中英文名称。

| MC021 | 精细背景简化人物格 | detailed-background simplified-character panel | 背景保持较多线条与空间信息，人物则以少量轮廓融入场景。 |
| MC022 | 精描人物简化背景格 | detailed-character minimal-background panel | 把线条、质感与神情集中在人物上，仅以少量环境线索交代位置。 |
| MC023 | 前景遮挡窥视格 | foreground-occlusion peeking panel | 让近处门缝、帘边或物件挡住部分画面，形成窥视与空间层次。 |
| MC024 | 倒影传情叙事格 | reflection-led emotional comic panel | 把镜面或水面倒影作为主要表情信息，主体的真实身影仅部分出现。 |
| MC025 | 物件留痕叙事格 | object-trace storytelling panel | 以人物留下的物件、温度或使用痕迹传达她的存在与离开。 |
| MC026 | 回忆意象叠画格 | superimposed-memory comic panel | 把较淡的回忆形象叠入当前画面，让同一格容纳人物的联想与记忆。 |
| MC027 | 轮廓白边分离背景格 | white-halo character separation panel | 在人物轮廓外留出细窄白边，把主体从密集黑线或网点中分离出来。 |
| MC028 | 门窗框中框叙事格 | doorway frame-within-frame comic panel | 借场景里的门窗或拱廊形成内层框景，把人物放在被框定的空间里。 |
