# 女性身体年龄阶段并排对照

第23版新增32幅图：16个年龄阶段各一幅正面和侧身参考。打开 [年龄阶段对照页](../index.html?section=female_life_stages)，默认先看同一标尺、同一脚底基线的连续年龄轮廓；切换“放大细看”可以在图内横向滚动。点击人物查看该阶段说明。

各阶段采用相近的普通长袖上衣、长裤和平底鞋，减少服装和多种体型造成的干扰。婴幼儿俯视卧姿与卧姿侧视另组比较，不与站立身高混排。原有面容、全身及成年尺寸资料在“全部参考词条”中继续提供。

图例是完整着装的原创年龄阶段示例，标尺只用于保持图内相对大小。青春期的变化时序和各阶段体态有个体差异，不是临床发育分级或平均体型标准。
