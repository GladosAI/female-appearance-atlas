# 更多职业、舞台与奇幻身份装扮

第27版新增 **32种身份，每种2套，共64套配图**。按4个类别组织，每类8种，选择“细分”即可只看某一种的两套结构。打开 [职业、舞台与特殊装扮总目录](../index.html?section=topic_role_costumes)。

全部采用25岁以上成年原创角色。服装主体、头饰、手套、鞋靴与携行道具均在词条中拆分；同种两套比较实际衣物结构与层次，不只更换颜色。专业和文化题材均为角色设计灵感，具体情境另行标明。
