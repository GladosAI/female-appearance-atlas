## 使用方法

先选择想表现的气质，再查看同一标签的两套造型。可以把“活泼”的姿态、“含蓄”的表情和“张扬”的配色组合；词条可单独添加到外观卡。露肤类别可按肩、背、腰、腿、领口和侧面切换。图例展示服装覆盖范围，全部保留不透明衣物覆盖私密部位。
