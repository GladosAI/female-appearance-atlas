# 镜头语言与叙事

[打开主图鉴 · 36项](../index.html?section=branch_camera_language) · [全部视角与拍摄资料](camera-visuals.md)

每项是一条从左到右阅读的三格分镜。推拉是机位移动，变焦是焦距变化，转焦改变清晰的距离层次；长镜头指连续拍摄而不是长焦。主观视点和建立、反应等功能可与不同景别、构图组合。

| 编号 | 镜头语言 | 分镜顺序 | 含义 |
| --- | --- | --- | --- |
| MV001 | 固定镜头（locked-off shot） | 入画 → 经过 → 出画 | 机位与构图保持不动，让人物或环境在画面内发生变化。 |
| MV002 | 推镜头（dolly in） | 较远 → 靠近 → 更近 | 相机向主体靠近，画面逐渐收紧，同时改变前后景的透视关系。 |
| MV003 | 拉镜头（dolly out） | 较近 → 后退 → 环境显露 | 相机离开主体，逐渐显露更大的环境与人物所处空间。 |
| MV004 | 水平摇镜（horizontal pan） | 起幅 → 横向扫过 → 落幅 | 相机位置基本不变，绕支点向左或向右转动观察方向。 |
| MV005 | 俯仰摇镜（vertical tilt） | 脚部 → 躯干 → 头部上方 | 相机位置基本不变，镜头绕支点向上或向下转动。 |
| MV006 | 横移跟拍（lateral tracking shot） | 起步 → 并行 → 继续跟随 | 相机沿人物一侧移动并跟随，近处与远处物体产生不同的位移。 |
| MV007 | 背后跟随镜头（rear follow shot） | 跟上人物 → 进入空间 → 继续前进 | 相机在人物身后移动，跟随其进入或穿过空间。 |
| MV008 | 环绕镜头（orbit or arc shot） | 斜前 → 侧面 → 斜后 | 相机围绕主体移动，连续改变人物朝向与背景关系。 |
| MV009 | 升降镜头（crane or boom shot） | 低位 → 平视附近 → 高位 | 相机整体升高或降低，改变观察高度和空间层次。 |
| MV010 | 甩镜头（whip pan） | 起幅清晰 → 快速模糊 → 落幅清晰 | 快速摇向另一处，以运动模糊连接起幅与落幅。 |
| MV011 | 手持跟拍（handheld following shot） | 手持取景 → 轻微偏移 → 继续观察 | 用手持方式跟随人物，画面带有轻微不规则的位移或倾斜。 |
| MV012 | 稳定器跟随镜头（stabilized following shot） | 平稳起步 → 保持构图 → 连续跟随 | 相机跟随人物移动，尽量保持水平线、主体位置与运动连贯。 |
| ZT001 | 变焦推近（zoom in） | 宽取景 → 变焦中 → 窄取景 | 机位保持不动，通过改变焦距逐渐收紧取景范围。 |
| ZT002 | 变焦拉远（zoom out） | 窄取景 → 变焦中 → 宽取景 | 机位保持不动，通过改变焦距逐渐扩大取景范围。 |
| ZT003 | 滑动变焦（dolly zoom） | 主体大小稳定 → 移动并反向变焦 → 背景关系改变 | 让机位移动与反向变焦配合，主体大小相对稳定而背景空间观感改变。 |
| ZT004 | 转焦镜头（rack focus） | 前景清晰 → 焦点过渡 → 后景清晰 | 在同一段镜头中把清晰焦点从一个距离层次转到另一个层次。 |
| ZT005 | 慢动作（slow motion） | 动作开始 → 细分阶段 → 动作延续 | 让动作在回放中显得更慢，突出动作阶段与细节。 |
| ZT006 | 延时摄影（time-lapse） | 较早 → 时间流逝 → 较晚 | 间隔采样并压缩时间，突出云、日影或人流等较长时间的变化。 |
| ZT007 | 高速快门凝固动作（freeze action with a fast shutter） | 起跳 → 空中瞬间 → 落地阶段 | 用较短曝光把快速动作记录得较清晰，突出关键瞬间。 |
| ZT008 | 慢门运动拖影（slow-shutter motion blur） | 运动开始 → 轨迹延展 → 运动继续 | 较长曝光让运动部位形成模糊或拖影，静止环境仍可相对清楚。 |
| NS001 | 主观镜头（point-of-view shot） | 观看者 → 角色所见 → 观看回应 | 从角色的观看位置呈现所见对象，让观众暂时共享角色视点。 |
| NS002 | 客观旁观镜头（objective observer shot） | 外部观察 → 人物行动 → 继续旁观 | 从角色之外观察人物与空间，不直接代入某一角色的眼睛。 |
| NS003 | 建立镜头（establishing shot） | 交代空间 → 人物进入 → 进入情节 | 先交代地点、人物位置和空间关系，为后续近景提供环境背景。 |
| NS004 | 反应镜头（reaction shot） | 平静 → 察觉 → 反应 | 把注意力放在角色对事件或他人话语产生的表情与动作反应。 |
| NS005 | 插入细节镜头（insert shot） | 主要动作 → 关键细节 → 返回动作 | 短暂突出主动作中的关键细节，如拿钥匙的手或正在操作的物件。 |
| NS006 | 切出镜头（cutaway shot） | 主要场景 → 相关对象 → 返回场景 | 暂时切向主动作之外但与叙事有关的对象，再返回原场景。 |
| NS007 | 空镜头（empty or environmental cutaway shot） | 环境 → 物件或光影 → 气氛延续 | 以环境或物件为主体，不让主要人物直接占据画面。 |
| NS008 | 双人关系镜头（two-shot） | 两人同框 → 交流 → 关系延续 | 在同一画面中容纳两名人物，让距离、朝向和动作共同表达关系。 |
| SE001 | 正反打（shot/reverse shot） | 人物A → 人物B → 返回A | 在交流双方的观察方向之间交替切换，建立对话或对峙关系。 |
| SE002 | 视线匹配剪辑（eyeline match） | 角色看向 → 对应对象 → 角色回应 | 将角色的观看动作与随后呈现的所见对象连接起来。 |
| SE003 | 动作衔接剪辑（cutting on action） | 动作开始 → 动作中切镜 → 动作完成 | 在动作进行中切换机位，让动作阶段衔接，保持时间与空间的连贯。 |
| SE004 | 图形匹配转场（graphic match cut） | 圆形对象A → 形状呼应B → 视觉关联C | 利用形状、位置或构图的相似性，将不同镜头连接起来。 |
| SE005 | 交叉剪辑（cross-cutting） | 场景A → 场景B → 返回A | 在不同地点的事件之间来回切换，常用来提示同时发生或相互关联。 |
| SE006 | 跳切（jump cut） | 同机位片段A → 时间省略 → 片段B | 从同一连续素材或近似机位中省去一段过程，产生可感知的时间跳跃。 |
| SE007 | 蒙太奇段落（montage sequence） | 准备 → 途中 → 抵达 | 把多个时间或场景的片段组合，压缩过程或建立概念关联。 |
| SE008 | 连续长镜头（long take） | 连续起始 → 连续经过 → 连续结束 | 在一次持续拍摄中展开人物行动，镜头内部不发生剪辑切换。 |
