# 女性各年龄段图鉴

当前96项：连续年龄阶段正面与侧身32项，原有头部和全身32项，另有身高整体比例16项与成年三围16项，覆盖新生儿、婴幼儿、儿童、青少年、青年成人、中年、年长与高龄。页面默认显示 [年龄阶段并排对照](life-stage-comparison.md)，其正面与侧身按统一示意标尺和脚底基线显示，婴幼儿卧姿另组。所有阶段完整适龄着装。原始图页的各格按便于阅读的比例排版，格内人物高度不代表同一现实身高标尺；年龄是设定标签，个体外观存在差异。身高与三围数值另见 [尺寸设定专题](age-size-atlas.md)，所有数字为虚构创作设定，三围仅列成年参考。
