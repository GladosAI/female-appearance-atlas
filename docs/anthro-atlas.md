共 180 项，包含兽化专题 128 项、复合躯体 32 项，完整四足动物4项，以及已有16项自然耳角、尾翼、鳞毛和瞳孔参考。程度对照、兽脸毛纹、自然耳尾与爪足、物种原型各32项，每项有图。

[完全动物体态与四足装饰](../index.html?section=quadruped_forms)保留完整动物头颈与横向躯干，四脚着地；小马、狐狸与猫仅配少量装饰。它与BS016双足马型、HY017人形上身半人马分别归类，不修改L1—L8含义。

[半人形与复合躯体](../index.html?section=hybrid_body_forms)展示蛇尾、鱼尾、四足兽体、节肢和触腕等下身结构，不套用双足兽化程度分档。

## 8档创作对照

这些是本图鉴的形态标签，不是生物比例、演化顺序或福瑞社群的统一标准。兽脸、手足、被毛、体态可以分别选择，例如采用完整狐头，同时保留人形操作手与跖行足。

| 档位 | 名称 | 本档观察重点 |
| --- | --- | --- |
| L1 | 人形兽耳 | 人脸、人手、人足，仅替换为一对动物耳，无尾巴。 |
| L2 | 人形耳尾 | 保留人脸人手足，增加与身体相接的动物尾巴。 |
| L3 | 局部皮毛 | 人脸轮廓保留，面颊与前臂出现局部被毛，手足仍偏人形。 |
| L4 | 局部兽手兽足 | 人脸保留，手足成为拟人爪掌，四肢局部被毛。 |
| L5 | 短吻兽脸 | 头部短吻与毛脸，躯干比例及手足仍以人形为主。 |
| L6 | 完整兽头人形躯干 | 动物头部有完整吻部，身躯比例、人形手足仍保留。 |
| L7 | 全身拟人兽型 | 兽头、全身被毛与爪掌，保持直立的人形躯干比例。 |
| L8 | 偏兽体态直立 | 直立角色采用更明显动物头身比例与支撑轮廓，保留服装与操作能力。 |

程度图用相近的普通外套与长裤对照，按自然兽化部位区分。兽耳、尾、翼和毛爪属于角色的幻想身体形态；[Cosplay专题](cosplay-atlas.md)中的发箍、挂尾、假毛、翼架属于穿戴部件。两者可在设计中组合，连接方式应明确。

## 组合时记录

记录头脸与吻部、耳的位置及数量、被毛/鳞羽区域、操作手的指型、足部接地方式、尾翼根部及服装开口。趾行图突出抬高的踝跟与趾部支撑，避免把膝画成反向折弯。鸟足、分蹄、单蹄及拟人四指/五指手分别标注；这里的双足与操作手是角色创作改编，不能当真实动物的解剖标准。

鳞羽、水生、昆虫与龙、狮鹫等作为拟人形态拓展单列，保留可识别的种类特征；不给每种角色都套猫耳与猫尾。物种特征不决定角色的性格或行为。直立及半人形图采用成年女性幻想角色与普通完整服装；完整四足图保留动物身体，仅配少量饰物，不套用人类身体或年龄。
