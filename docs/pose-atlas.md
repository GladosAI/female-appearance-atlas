# 体态与动作图鉴

原有236项动作继续保留，第54版再增加64项镜头摆姿、坐卧构图、日常操作、舞台、运动、施法与双人互动，共 **300项动作参考**；另有24项柔韧姿态单列。“坐姿、蹲跪与起身”保留48项，含二郎腿、四字腿、单膝跪、跪坐与起身过渡。打开 [体态与动作](../index.html?section=pose)，或直接进入 [坐姿、蹲跪与起身](../index.html?section=pose&dimension=%E5%9D%90%E5%A7%BF%E3%80%81%E8%B9%B2%E8%B7%AA%E4%B8%8E%E8%B5%B7%E8%BA%AB)。

新增卡片标明视角、动作阶段和主要支撑点；人物采用完整不透明衣着。站立、坐卧、腾空和双人接触使用不同的支撑关系，先比较整体动作线，再观察肩髋旋转与肢体遮挡。卧姿、上肢、双人与运动组采用较宽图页，人物、手足和必要支撑物完整保留。

拍照时的自拍、写真与多人站位另见 [摄影摆姿与合影48项](../index.html?section=photo_poses)；[拍照Pose详表](photo-poses-v55.md)按景别、机位与视线浏览。
