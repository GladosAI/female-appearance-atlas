# 女性角色外观卡模板

把词条当作可组合部件，先描述可见形态，再说明它如何配合角色的生活、职业或战斗需求。

## 基础信息

- 角色名与角色编号：
- 设定年龄与呈现年龄感：
- 场景、地域与时代设定：
- 画风、头身比与目标显示尺寸：
- 身高、骨架、肌肉与软组织体积：

## 头部

- 脸部轮廓与侧面轮廓：
- 眼形、虹膜、眼间距与眉形：
- 鼻、嘴、耳部与固定标记：
- 发长、剪裁、刘海、分缝：
- 扎法、编法、发质、主色与染色分区：
- 发根固定点、发束数量和运动范围：

## 服装与装备

- 内层、中层、外层与鞋袜：
- 整体轮廓、腰线、领型、袖型和长度：
- 材质的厚薄、软硬、重量与光泽：
- 主色、辅色、重点色与纹样尺度：
- 配饰的固定点、道具的握持点与携行位置：
- 历史实物参考或灵感改编说明：

## 体态与差分

- 默认重心、站姿、坐姿和习惯手势：
- 行走、跑步、战斗与道具使用的动作规则：
- 表情基准与需要的差分：
- 换装或变身变化部件：
- 伤痕、痣、纹身和印记的三视图位置：

## 固定识别点

记录三至五个在头像、半身与全身图中仍能辨认的特征：

1. 头部轮廓或发束：
2. 五官或稳定标记：
3. 衣物大轮廓：
4. 道具或配饰：
5. 配色关系：

## 美术交付

- 正面、侧面、背面与常用四分之三视角：
- 黑色剪影、头像缩略图与去色对比：
- 头发前后层、躯干、手臂、衣摆、披风、饰品和道具拆层：
- 背部衣物、扎发固定点与额外器官接点：
- 关节活动、布料受力和穿插检查：
- 参考链接、作者或馆藏、日期与图片使用条件：

## 可复制的文字描述

一位【年龄设定】的女性角色，具有【身高与体格】、【脸部轮廓】和【五官特征】；头发为【发色与发质】，采用【长度＋剪裁＋刘海＋扎法】。穿着【内层＋外层＋下装或连身衣物】，以【材质、配色与纹样】呈现；佩戴【固定配饰】，携带【道具】。默认姿态为【重心与手势】，固定识别点为【三至五项】。以【画风与比例】绘制正面、侧面、背面和需要的表情差分。
